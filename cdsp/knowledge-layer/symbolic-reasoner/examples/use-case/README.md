# Legacy Use-Case Example

This directory preserves the earlier combined `model_config.json` layout for
reference. It is not the active reasoner-configuration format.

New configurations keep transport inputs and RDF shapes in the model
configuration, then reference a separate `reasoner_profile`. See the active
[driving-style example](../driving_style/README.md) and the
[reasoner-profile documentation](../../services/README.md).
